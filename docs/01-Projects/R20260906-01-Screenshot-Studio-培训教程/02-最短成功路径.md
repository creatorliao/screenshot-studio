# 02 · 最短成功路径

> 这一课只做一件事：从「打开编辑器」到「导出一张图」。不展开任何旁支，中间所有细节都写成「先跳过，见 03/04」。

---

## 本课目标

1. 沿最短路径独立完成一次「素材进 → 导出一张 PNG」。
2. 知道这条最短路径是心智模型 7 格的压缩版：① → ② → ⑦。
3. 第一张图出来之后，你就有资格判断后面各课「值不值得学」。

---

## 它在模型的哪一格

最短路径只走三格：

```
① 获得画面 → ② 定画幅 → ⑦ 导出
```

中间的 ③ 样机/画框、④ 背景/深度、⑤ 标注/文字在本课**全部跳过**（不是不存在，是暂时不碰，见 03）。

---

## 跟做步骤

1. 打开编辑器（线上 `screenshot-studio.com` 或本地 `localhost:3000`）。
2. 准备一张现成截图（产品界面、网页、App 截图都行，PNG/JPG/WEBP，≤100MB）。
3. 把图拖进中央空态区，或点击浏览选择，或直接 `Ctrl/Cmd + V` 粘贴。

   **你应该看到什么**：图片进入画布，左右两侧面板出现，顶部出现更多按钮（Copy、Save、Remove 等）。

4. 顶部点画幅按钮（默认显示 `4:3` 之类），选一个 `16:9 Landscape`。

   **你应该看到什么**：画布比例变成 16:9，图还在画布中央。

5. 点顶部 **Save** 按钮，弹出导出面板。
6. 导出面板里确认：Format 选 **PNG**，Quality 选 **High**，Resolution 选 **2x**。
7. 点 **Export as PNG**。

   **你应该看到什么**：出现进度条 → 浏览器下载一个名为 `screenshot-studio-<时间戳>.png` 的文件 → 右下角一条成功提示，并可能有彩带动画。

8. 打开下载的 PNG 看结果：这是你导出的第一张图。

## 迁移练习

**任务**：换一张你自己的图，仍走同一条最短路径。

- 可用条件：一张新图（和跟做示例不同的素材）；其余操作不变。
- 怎样算做成：你用新图独立完成「放入画布 → 选画幅 → 导出 PNG」，并且**不看本课步骤**也能点对 Save 里的三个选项（Format / Quality / Resolution）。
