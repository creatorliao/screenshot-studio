### 2.3 P0-4 修「换主图」路径（治 R2 —— 本次最高优先级功能修复）

改造前用户**没有任何一条**"换主图但保留我的样式"的路径（`03-分析报告` §3 R2 的五种尝试全部走不通）。现在：

- 新增 store 动作 `replaceMainImage(file, { resetStyles })`：只换主图，不动背景/阴影/圆角/缩放/滤镜/文字/贴纸/标注/动效。
  - 同时把该图所在的幻灯片 `src` 一起换掉，并在**确认没有别的幻灯片还引用旧 URL** 之后才 `revokeObjectURL`（改造前 `setImage` 直接回收，会连带打断仍指向它的缩略图）。
- 拖放/粘贴落在已有主图上 → 默认**替换主图（保留样式）**；按住 **Shift** 才是"添加为贴纸"。
  - 拖拽浮层实时改文案：「松开即替换主图，已调好的背景与文字会保留」/「按住 Shift 松开 = 添加为贴纸」—— 结果不再静默。
- 多文件时首张换主图、其余转为贴纸，**不再静默丢弃**。

### 2.4 P0-4 空画布不再渲染无效控件（治 R1）

- 新增 `hooks/use-has-renderable-content.ts`：把改造前**三套不等价**的"有没有图"判据收成一处
  （`EditorCanvas` 要两个 store 都认、`EditorHeader` 只看 `screenshot.src`、`ClientCanvas` 又是第三种）。
  取**最严**口径（两个 store 都认），因为 `screenshot.src` 才是 `ClientCanvas` 真正渲染的字段。
  → 主图加载失败时头部与画布不再判断分裂。
- `EditorLayout`：空画布时**收起** `LeftEditPanel`、`RightSettingsPanel` 与移动端「设置」入口。
- 实测效果：`/` 页面可见中文字符由 **948 → 464** —— 少掉的正是那堆"点了没反应"的控件文案。

### 2.5 P1-1 首屏引导式导入（治 R1，用户投诉第一条）

- **常驻「导入 / 替换图片」**：头部 Logo 右侧。空画布叫「导入」，有图叫「替换图片」并保留样式。
- **`CleanUploadState` 重写**：
  - 大标题「把图片放进来」（改造前是"一个加号 + 一行小字 + 一个 URL 框"混在一起让人猜）。
  - 三个**带文字**的并列入口：选择文件 / 网页截图 / 粘贴或拖放。
  - URL 输入框改为**点开才出现**（渐进披露），不再与主入口抢注意力。
  - 补上原本完全缺失的信息：`支持 PNG / JPG / WebP，单个最大 100MB`（直接取 `lib/constants.ts`，不写死）+ 「导入后可以调整画幅、背景和文字」。
- **`PostImportHint`**：导入后给一行"下一步"指引，可关闭且写 `localStorage`，老用户第二次进来不会再看到
  （对齐 `04-方案` §1 P6「引导式导入，但绝不强制」）。

### 2.6 统一导入语义与校验（治 R5）

- 新增 `lib/editor/import-image.ts`：拖拽 / 点击浏览 / 粘贴 / 头部「导入」四条入口共用一个 `importImageFiles()`。
  - 改造前 **4 套校验口径**（全局只校验第 1 张、`Add Slide` 完全不校验、贴纸入口不校验、设备屏不校验）与 **5 种错误文案** → 收成一套。

- 消除**拖拽/粘贴的双重响应**（改造前同一张图被消费两次：先成主图、300ms 后又成一张贴纸）：
  - 新增 `data-upload-dropzone` + `isUploadDropzoneTarget()`，让 `GlobalDropZone` 对落在首屏上传区内的拖放让路（沿用设备屏已有的仲裁模式）。

### 已知不足（本次引入或未消除）

1. **渐变的候选名是从常量 key 派生的英文**（`magic_aurora` → `Aurora`、`vibrant_orange_pink` → `Vibrant Orange Pink`）。
   比改造前"什么都没有"强得多，也让搜索有意义，但不是中文。要真中文化需给 214 条逐条起名，属独立工作量。
2. **背景面板的"最近使用/收藏"只存 value，不存缩略图**；如果某张图从 R2 下架，收藏里会出现一个空白块（不会报错）。
3. **`demo` 分类补回后，图片类候选从 88 张变 99 张** —— 这是把原本不可达的 11 张放出来，不是新增素材。
4. **`PostImportHint` 的关闭是全局一次性的**，不区分"第一次导入"还是"第 N 次"；用户关掉后不会再看到。
5. **阴影强度滑块只在"特效"Tab 里出现**，且它与图层面板里那一层的 opacity 是同一个值（两处可改，但不再是"必须跨 Tab 才能改"）。
