**关键事实：桌面端与移动端是两套不同的信息架构。**

- `UnifiedRightPanel` 在桌面端**完全不挂载**：`EditorLayout.tsx:98,136` 是 `!isMobile &&`，`:138-151` 才在 `isMobile && <Sheet>` 内挂载。`EditorLayout.tsx:59-65` 的注释也明说它只在 sheet 打开时挂载。

由此产生 **3 项桌面端独缺的能力**：

| 缺失项 | 唯一渲染点 | 桌面端后果 |
|--------|-----------|-----------|
| `ImagePositionSection`（3×3「位置」九宫格 + Auto） | `unified-right-panel.tsx:166` | 桌面端**没有**任何"把图摆到某个位置"的具名控件，只能去右栏 3D Tab 在 260px 宽的小预览图上拖 |

### 3.3 背景面板的 7 项具体缺陷（全部有代码证据）

1. **渐变色块 32px 且完全无标签**：`h-8 w-8`（`BackgroundSection.tsx:351,380,402`），且**无 `alt`/`title`/`aria-label`**（`:343-361`、`:372-414`）。对比图片缩略图有 `alt`（`:313`）。同色系渐变肉眼几乎无法区分。
2. **横向滚动条被彻底隐藏**：容器 `overflow-x-auto scrollbar-hide`（`:338,367`），`app/globals.css:373-379` 在 Firefox/WebKit 下隐藏滚动条 → 用户不知道右边还有 4–10 屏内容。
3. **无 hover 预览**：`components/editor/**` 全目录 grep `onMouseEnter|onPointerEnter` **零命中**。
4. **无搜索、无筛选**：该文件无任何搜索/筛选 state。
5. **无收藏、无最近使用**：无相关状态或 UI。
6. **选中态是两套语言**：图片类用「加边框 + ring」（`:306-308`），渐变类用「变圆 + 放大 110% + ring」（`:352-353,381-382,403-404`），**都没有对勾、没有名字**。
7. **"自定义背景"三格的高亮是错的**：`customBgType` 只认 `solid+transparent` / `solid+#` / `solid+rgba` / `image+blob:`（`:54-68`）→ 用预设图或渐变时**三格全都不高亮**，用户看不出当前背景类型。

### 3.4 阴影（「光与影」）的隐藏代价

- 19 个阴影资源已定义（`:21-24`），UI 只渲染**前 11 个**（`:182` `slice(0, 11)`）→ 8 个不可达。
- 阴影**不是背景属性，而是往图层栈塞一张全画布覆盖图**（`handleAddShadow`，`:119-139`）：先删掉所有含 `overlay-shadow` 的叠加层（**同时只能有 1 个阴影**），再加一层，`opacity` 硬编码 `0.5`、`size = max(画布宽,高)`。
- 想微调这个阴影，必须切到「图层」Tab 找到它（`DepthSection.tsx:412-423`）→ **调一次阴影要跨 2 个 Tab**。
- 上传自定义背景后的「删除」语义错误：`:278-281` 把背景强制设成 `vibrant_orange_pink` 渐变，**不是恢复上传前的状态**。

## 4. 文字 / 标注 / 图层链路

### 4.1 文本框（用户核心工作流第 3 步）

- **唯一创建入口**：`components/text-overlay/text-overlay-controls.tsx:83-89` 的「添加文字」按钮（虚线框样式），由 `TextSection`（标题「添加文字」）包一层，挂在左栏「设计」Tab **第 6 个区块**（`LeftEditPanel.tsx:149`）。
- **必须滚动才能看到**：它前面有 样式、边框、阴影、添加推文、代码图片卡片、贴纸、绘制与标注 共 7 个区块，**其中 6 个 `defaultOpen=true`**。
- 默认值（`:53-70`）：`text: '文字'`、位置 `{x:50,y:50}`（百分比，即画面正中）、`fontSize 24`、`fontFamily 'system'`、`color '#ffffff'`（**白字**）。
- 创建后自动选中最新一条并 focus 输入框（`:44-49,72-77`）—— 这一点做得好。
- 可调属性：内容 textarea、颜色（8 快捷色 + 取色器）、字体、字重（9 档）、字号 8–150、不透明度、方向（水平/垂直）、文字阴影（开关 + blur + X/Y 偏移）。
- **不存在**：旋转、对齐、行高/字距、层级前后、锁定、富文本（字段全集见 `lib/store/index.ts:58-70`）；**位置没有数值输入，只能画布拖动**（`HTMLTextOverlayLayer.tsx:56-67`）。
- 渲染端把字重归并成 `bold/normal`（`HTMLTextOverlayLayer.tsx:101-102`），**500/600/900 视觉无差别**；`italic` 判定存在但字重选项里没有 italic。

### 4.2 标注

- 6 种工具：`arrow / curved-arrow / line / rectangle / circle / blur`（`AnnotateSection.tsx:13-72`）。
- **创建方式**：点工具 → 画布按下并拖拽 → 松手位移 > 5px 才落形状（`SVGAnnotationLayer.tsx:446`）→ **工具自动取消**（`:481`），即"一次工具只画一个形状"。
- 选中后可拖动整体、拖端点、拖曲线控制点、Delete 删除、Esc 取消（`:485-651`）。
- 模糊区域是独立 state（`BlurRegion`），列表中每条一个 2–30 滑块 + 删除（`AnnotateSection.tsx:251-280`）。

### 4.3 图层管理

- **有统一图层列表**：`DepthSection.tsx:97-149` 把 图片叠加 / 文字 / 标注 / 模糊 四类合成一个数组，渲染在左栏「图层」Tab（`:251`，倒序显示）。
- 可做：选中、显隐、删除；**排序只有图片叠加层能 up/down**（`:368-384`），文字/标注/模糊**不能排序**；图片叠加层另有"移到最前/移到图片后面"（`:386-402`）。
- **不能重命名**（label 只读，`:319`）；**不能锁定**。
- 属性面板只在选中**图片叠加层**时出现（`:412-423`）；选中文字层不会在这里出现属性。
- 另有画布内的 Moveable 变换框与浮动工具条（`HTMLImageOverlayLayer.tsx:245-305`、`ContextToolbar:119-183`）。
- `CanvasObjectTopControls.tsx`（旋转+删除手柄）只服务于**主图与设备样机**，不服务于文字/贴纸。
