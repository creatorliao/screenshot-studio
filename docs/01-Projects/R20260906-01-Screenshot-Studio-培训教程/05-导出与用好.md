# 05 · 导出与用好

> 这一课把模型最后一格 ⑦ 展开：按用途选格式、质量、倍率；用产品里已有的能力把图「用好」，不编造技巧。

---

## 本课目标

1. 说清 PNG / JPEG / WebP 三种格式各自适合什么场景。
2. 按「发推 / 放进幻灯 / 留底稿」三种不同用途，选出不同的格式与倍率。
3. 知道 Copy（复制到剪贴板）与 Export Video（导出视频）分别解决什么。

---

## 它在模型的哪一格

```
… ⑤ 标注与文字 → ⑦ 导出（本课）
```

导出是主路径的最后一格。决策顺序固定：**先用途 → 再格式 → 再质量 → 再倍率**，这也是导出弹窗里选项的排列顺序。

---

## 跟做步骤

### 图片导出（Header → Save）

1. 做完一张图后，点顶部 **Save**。
2. 弹窗里依次看到三组选项：

   | 组 | 选项 | 作用 |
   |----|------|------|
   | Format | JPEG / PNG / WebP | 文件格式 |
   | Quality | High / Medium / Low | 压缩质量 |
   | Resolution | 1x (FHD) / 2x (4K) / 3x (6K) | 输出倍率 |

3. 选一组，点 **Export as <格式>**，浏览器下载文件。

**三种格式怎么选**（来自导出组件里写的描述，非编造）：

- **PNG**：Lossless（无损），支持透明背景。适合「留底稿 / 要透明 / 要最大清晰度」。
- **JPEG**：Smaller files（更小），适合「发微信 / 发网页 / 不需要透明」。
- **WebP**：Best compression（压缩最好），小而清晰，适合「现代网页 / 追求小体积」。

**倍率怎么选**（来自 `ScaleSlider.tsx` 的固定档位）：

- **1x (FHD)**：1080p 级别，发社交媒体够用。
- **2x (4K)**：默认值，清晰度高、文件适中，多数场景用这个。
- **3x (6K)**：最大，适合要放大看细节或打印。

**你应该看到什么**：进度条走完，浏览器下载文件，右下角成功提示；导出的文件名形如 `screenshot-studio-<时间戳>.png`。

### 复制到剪贴板（Header → Copy）

1. 点顶部 **Copy**。

**你应该看到什么**：进度条走完，图片进剪贴板，可直接粘贴到文档、聊天、PPT 里。

**证据**：`hooks/useExport.ts`（`copyImage` 固定以 PNG 2x 写入剪贴板）。

### 导出视频（Header → Export Video，支线入口）

只有在有动画或多张图时才出现。详见 04 课；这里只记住它解决「动起来 / 多张图连播」的场景。

## 迁移练习

**任务**：为三种用途分别导出（或至少选出）三组规格。

- 用途 A「发推」：给 Twitter/X 用的图。
- 用途 B「放进幻灯/文档」：要清晰、可能要透明底。
- 用途 C「留底稿」：要可再编辑、无损。

**怎样算做成**：你为 A、B、C 各写出一组（格式 + 质量 + 倍率），并各说一句理由；至少真正导出其中一种并核对文件名与格式。

> 提示：没有「唯一正确答案」，只要你的选择和用途对得上、且用了产品里真实存在的选项即可。产品里没有的选项（如 5x、GIF）不要写。
