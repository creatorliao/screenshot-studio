## 0. 结论先行

**不是"没预留中文"，也不是"启动参数把语言钉死了"，而是"中文译文预留了，但整个 UI 层从未接线"。**

三条一句话结论：

1. 简体中文译文**是齐的**：`messages/zh.json` 与 `messages/en.json` 键完全对齐（各 135 键，无缺失、无多余）。
2. 语言路由**是通的**：`Accept-Language: zh-CN` 实测能把 `/` 重定向到 `/zh`，`<html lang>` 也正确变成 `zh`。
3. 但 `/zh` 上**一个中文字符都不显示**：全仓 0 处调用 `useTranslations`/`getTranslations`，约 750 处英文硬编码，译文只被塞进 RSC 序列化数据后丢弃。

所以当前**不存在任何能让用户看到中文界面的办法**——换 URL、切浏览器语言都不行。这是一个"半接线"的 i18n：路由层做完了，渲染层没做。

## 2. 关键取证回放

### 2.1 语言协商确实生效（推翻 H1 的"参数问题"）

```
$ curl -s -o NUL -D - -H "Accept-Language: zh-CN,zh;q=0.9" http://localhost:3111/
HTTP/1.1 307 Temporary Redirect
vary: Accept, Accept-Encoding
location: /zh

$ curl -s -o NUL -D - -H "Accept-Language: ja-JP,ja;q=0.9" http://localhost:3111/
HTTP/1.1 307 Temporary Redirect
location: /ja

$ curl -s -o NUL -D - -H "Accept-Language: en-US,en;q=0.9" http://localhost:3111/
HTTP/1.1 200 OK          ← 不重定向，走默认英文

$ curl -s -o NUL -D - http://localhost:3111/          # 无 Accept-Language
HTTP/1.1 200 OK
```

`package.json:6` 的启动脚本是 `npx prisma generate && next dev --webpack`，**不含任何语言相关参数**。
结论：默认启动参数没有把语言钉在英文。

### 2.2 但 /zh 上一个中文字都不显示（证实 H3）

```
$ curl -s -H "Accept-Language: zh-CN" http://localhost:3111/zh    # 原始 HTML
  HTML 长度        233410
  含中文字符         1546      ← 看着像有中文
  <html lang>       zh

$ 同上，但先剔除 <script>/<style> 再统计
  可见 DOM 长度     173776
  可见 DOM 中文字符      0     ← 真正会被看到的文本里一个中文都没有
```

对照多个页面：

| 页面 | `<html lang>` | 可见 DOM 中文字符 |
|------|---------------|-------------------|
| `/`（英文） | `en` | 0 |
| `/zh` | `zh` | **0** |
| `/zh/about` | `zh` | **0** |
| `/zh/privacy-policy` | `zh` | **0** |
| `/zh/landing` | `zh` | **0** |
| `/zh/tools` | `zh` | **0** |

那 1546 个中文字符在哪？在 RSC 序列化脚本里：

```
首个中文字符位于第 215526 字节，其前文为：
  ..."$Lb2",null,{"formats":"$undefined","locale":"zh","messages":{"common":
  {"openEditor":"打开编辑器","startCreating":"开始创作",...
```

即：`NextIntlClientProvider`（`app/[locale]/layout.tsx:36`，**未传 `messages` 属性**，自动继承服务端 catalog）
把整份 zh.json 序列化进了 flight data 发给浏览器，**但没有任何组件去读它**。
净效果：~9KB 译文白白随每次页面请求下发，仅此而已。

### 2.3 译文键对齐核验（推翻 H2）

对 `messages/en.json` 与 `messages/zh.json` 递归展平后取差集：

```
en keys: 135   zh keys: 135
missing in zh: （空）
extra  in zh: （空）
```

H2「根本没有预留简体中文文本」**不成立**。
