# 06 · 综合应用

> 这一课没有跟做步骤。关掉前面所有课，用一个**新任务**独立做一遍，再用模型复盘。
> 综合题与 02 课的示例不是同一张素材、同一个用途。

---

## 本课目标

1. 不看教程，用一个新素材 + 新用途，独立完成一次「素材进 → 导出」。
2. 至少覆盖模型的四格：取画面、一样机或背景、一处标注或文字、一次导出。
3. 用模型里的词，五句以内复盘自己做了哪些选择。

---

## 它在模型的哪一格

全模型。这就是本系列的「应用」层验收：你会不会在没人带的情况下，自己把 ①→⑦ 走一遍。

---

## 综合任务

**场景**：你要给一个开源项目写一篇发布公告，公告会发在 Twitter/X 上。你需要一张配图。

**题面**：

| 项 | 要求 |
|----|------|
| 给谁看 | 关注这个项目的开发者（X 时间线） |
| 用在哪 | 发布公告的配图（X 帖，16:9 横图） |
| 素材从哪来 | 你自己选一张截图：可以是真实项目界面、也可以用「输入网址截图」现场抓一个网页 |
| 必须用到的模型节点 | ① 获得画面、② 定画幅（16:9）、③ 样机或④ 背景（至少一处）、⑤ 标注或文字（至少一处）、⑦ 导出 |
| 怎样算做成 | 导出一张 PNG/JPEG/WebP；图里有你选的画幅、一样机或背景、一处标注或文字 |

**约束**（避免你抄 02 课）：

- 素材与 02 课的示例不同；
- 用途是「X 发布配图」，不是「随便导一张」；
- 至少改一处 03 课之外你之前没动过的设置（例如透明背景、或某个设备样机、或一个动画）。

---

## 建议走法（只是脚手架，不是答案）

1. 先定用途与画幅：X 帖配图 → 16:9 Landscape。
2. 获得画面：上传一张真实截图，或输入网址截一个网页。
3. 套一样机或调一背景：二选一（也可以都做）。
4. 加一处标注或文字：例如画个箭头指向关键功能，或加一行标题。
5. 导出：按「发 X」选格式与倍率（回顾 05 课）。

---

## 做完后：五句以内复盘

用模型里的词写复盘，例如：

> 我走的是「① 获得画面（上传截图）→ ② 定画幅（16:9）→ ③ 套浏览器样机 → ⑤ 加文字 → ⑦ 导出 PNG 2x」。我选择 PNG 是因为要清晰，选择 2x 是因为发 X 需要高清。没用动画（⑥），因为这是静态配图。

复盘里要出现至少 4 个模型节点名。
