## 本课目标

1. 在「定画幅 / 样机与画框 / 背景与深度 / 标注与文字」每个节点上，知道有什么、点哪里、看到什么。

## 跟做步骤

### ② 定画幅（顶部 Header）

1. 顶部点画幅按钮，打开选择器。
2. 在分类里找「用途」而不是找「比例」：要发 Instagram 就选 Instagram 下的 Square / Portrait / Story/Reel；要发推就选 Social Media 下的 Landscape。

**你应该看到什么**：画布比例立即变化；每个画幅都带描述与用途（如「YouTube, Twitter/X, Facebook Posts」）。

**证据**：`lib/constants/aspect-ratios.ts`（`category`、`useCase` 字段）、`components/aspect-ratio/aspect-ratio-picker.tsx`。

### ③ 套样机与画框（左栏 Mode 切换）

左栏顶部有 **Image / Browser / Device** 三档模式：

- **Image（图片）**：Design 面板给出 Style（Default / Glass Light / Glass Dark / Outline / Border / Border Dark）与 Border（Sharp / Curved / Round 圆角 + Radius 滑杆 + Scale）。
- **Browser（浏览器）**：选 Safari / Safari Dark / Chrome / Chrome Dark，可填 URL 与 Header size。
- **Device（设备）**：进入设备样机库（iPhone / Apple Watch / MacBook），最多 6 台，含 6 种布局（Center Stage、Duo Split、Trio Fan 等）。

跟做一次：

1. 切到 **Browser**，点 **Safari**，在 URL 框填 `yourapp.com`。

   **你应该看到什么**：图片被装进一个带三个圆点的 Safari 窗口，顶部显示你填的地址。

2. 切回 **Image**，在 Style 里点 **Glass Dark**，再用 Border 的 Radius 滑杆拖到 24。

   **你应该看到什么**：图片套上深色玻璃边框，圆角明显变大。

**证据**：`components/editor/LeftEditPanel.tsx`、`BrowserMockupSection.tsx`、`StyleSection.tsx`、`BorderSection.tsx`、`lib/constants/mockups.ts`。

### ④ 调背景与深度（左栏 BG / Layers 标签）

左栏三个标签：**Design / BG / Layers**。

- **BG** 标签：Light & Shadow（阴影贴图）、Custom Background（Image / Color / Transparent）、图片背景分类（Abstract / macOS / Radiant / Mesh / Raycast / Paper / Pattern）、Magic Gradients（可 SHUFFLE）、Gradients（经典 + mesh）。
- **Layers** 标签：图层列表（可见/顺序/前后）、属性（大小/旋转/翻转/不透明度/模糊）、3D Objects（几何体库 + 上传）。

跟做一次：

1. 切到 **BG** 标签，点 **Magic Gradients** 的 **SHUFFLE**，再点一个色块。

   **你应该看到什么**：背景变成随机渐变，画面氛围立刻变化。

2. 切到 **Layers** 标签，在 3D Objects 里点一个几何体（如 Sphere）。

   **你应该看到什么**：画布上多出一个可选中、可调大小/旋转的 3D 物体，Layer 列表里多出一行。

**证据**：`BackgroundSection.tsx`、`DepthSection.tsx`、`ImageOverlaySection.tsx`、`lib/r2-backgrounds.ts`、`lib/constants/gradient-colors.ts`。

### ⑤ 标注与文字（Design 面板）

在 Image 模式的 Design 面板里：

- **Draw & Markup**：Arrow / Curve / Line / Rect / Circle / Blur 六种工具，12 色 + 自定义色，Stroke 1–24px。
- **Add Text**：文字叠加，可调字体、字号、颜色、不透明度、横竖排、阴影。

跟做一次：

1. 点 **Arrow**，在画布上按住拖一条箭头指向图里的某处。

   **你应该看到什么**：一条箭头出现，选中它可改颜色与描边宽度。

2. 点 **Add Text**，输入一行标题，用面板调整字号与颜色。

   **你应该看到什么**：文字出现在画布上，可直接拖动位置。

**证据**：`AnnotateSection.tsx`、`TextSection.tsx`、`components/text-overlay/text-overlay-controls.tsx`。

## 迁移练习

**任务**：指定用途「放进文档的产品图」，自选一处样机与一处背景。

- 可用条件：一张产品截图；要求同时改「画框」和「背景」各一次，可再加一处标注。
- 怎样算做成：你选的样机与背景和跟做示例不同；最后导出一张 PNG；并能用模型里的词解释你改了哪几格（③ 或 ④ 或 ⑤）。
