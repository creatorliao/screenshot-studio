# 04 · 支线能力

> 这一课写主路径之外的支线，并且**每条都说明它从主路径哪一步分出去**。
> 只写仓库里真实存在的支线：代码出图、推文出图、动画与视频导出、多图幻灯片，以及独立于编辑器的图片工具集（Image Tools）。

---

## 本课目标

1. 说清各条支线各解决什么、从主路径哪里分出、做完后回到哪里。
2. 至少走通一条支线（推荐推文出图，最短）。
3. 知道图片工具集（Image Tools）与公开截图 API 的存在，二者都不经过编辑器主路径。

---

## 它在模型的哪一格

支线都挂在主路径的某一步上分叉：

```
主路径：① 获得画面 → ② 定画幅 → ③ 样机/画框 → ④ 背景/深度 → ⑤ 标注/文字 → ⑦ 导出
                ↑                      ↑                                    
           支线：推文出图          支线：动画（⑥）→ 视频导出
        （用推文链接代替上传）     （在 ③④ 之后加动效，或加多图）
另：代码出图（/code）与图片工具集（/tools）都是独立页，不经过主路径。
```

---

## 支线 A · 推文出图（最短，推荐先走）

**从哪分出**：① 获得画面。不传图，改用一条推文链接。

1. 打开编辑器，左侧 Design 面板里找到 **Add a Tweet**，展开。
2. 粘贴一条推文 URL（如 `https://x.com/user/status/123…`）或纯数字 ID。
3. 点 **Fetch tweet**，等它拉取并预览。
4. 用 Light / Dark 切换预览样式，满意后点 **Add to canvas**。

**你应该看到什么**：推文变成一张规整的卡片进入画布，之后可继续走 ②③④⑤ 的主路径。

**证据**：`components/editor/sections/TweetImportSection.tsx`、`app/api/tweet/[id]/route.ts`。

## 支线 B · 代码出图（独立页）

**从哪分出**：不经过编辑器主路径，直接访问 `/code`（线上 `screenshot-studio.com/code`）。

1. 打开 `/code`，看到一段默认代码示例。
2. 粘贴你的代码，底部控制条选 **Theme**（14 个主题）、**Language**（21 种）、**Background**（主题渐变 / 图片 / 图案，可关闭得透明底）、**Dark mode**、**Line numbers**、**Padding**（16/32/64/128）、**Window**（None / Mac）。
3. 点 **Export Image**（或按 `Cmd/Ctrl+S`）。

**你应该看到什么**：下载一张 `code-image.png`（可到 2x / 4x）。也可 **Copy Image**（`Cmd/Ctrl+Shift+C`）或 **Copy URL** 分享当前状态。

**证据**：`app/[locale]/code/page.tsx`、`components/code-image/CodeImageEditor.tsx`、`code-themes.ts`。

## 支线 C · 动画与视频导出

**从哪分出**：③④ 之后（画面已成型，想让它动起来），或加多图做幻灯片。

### C1 · 加动画

1. 右栏切到 **Motion** 标签，看到按 8 类分组的动画预设（Reveal / Slide / Fade / Flip / Perspective / Orbit / Depth / Ken Burns，共 35 个）。
2. 点一个预设卡片，画布下方自动出现时间轴。

**你应该看到什么**：动画被加进时间轴，卡片显示时长（如 1.2s），可点播放预览。

### C2 · 多图幻灯片

1. 顶部点 **Add Slide**，选多张图加入。

**你应该看到什么**：画布支持多页切换，Header 出现 **Export All（N）** 打包下载按钮。

### C3 · 导出视频

1. 点顶部 **Export Video**。
2. 弹窗里选 Export Type（Animation / Slideshow）、Format（MP4 H.264 / WebM VP8）、Quality（High / Medium / Low）；Slideshow 还可设每张时长。
3. 点 **Export as MP4/WebM**。

**你应该看到什么**：进度条走完，下载视频文件；MP4 需要支持 WebCodecs 的浏览器（Chrome 94+ / Edge 94+），不支持时按钮会提示。

**证据**：`components/editor/RightSettingsPanel.tsx`（Motion）、`lib/animation/presets.ts`、`components/timeline/`、`lib/export-slideshow-dialog.tsx`、`lib/export/video-encoder.ts`。

## 支线 D · 图片工具集（Image Tools，独立页套件）

**从哪分出**：不经过编辑器主路径，直接访问 `/tools`（线上 `screenshot-studio.com/tools`，导航栏也有 "Image Tools" 入口）。它与 `/code` 一样是独立页，但不是单个工具，而是一套 11 个单用途小工具。

**这套工具统一遵守三条规则**：

- **纯浏览器处理、不上传**。图片在本地用 Canvas + Web Worker 解码、处理、再编码，不会发给任何服务器（dropzone 明写 "processed in your browser, never uploaded"）。
- **批量进、打包出**。除裁剪外，其余工具都能一次拖入多张图，处理完「单张直接下载、多张打包成一个 zip」。
- **读 6 种、写 3 种格式**：读 PNG / JPG / WebP / GIF / BMP / AVIF；写 PNG / JPG / WebP（WebP 由浏览器能力自动探测，不支持时自动隐藏）。

### D1 · 五个主工具（都在 `/tools` 中心页）

1. **Compress（压缩）**：拖入图片 → 选压缩档位 **Light / Balanced / Strong / Extreme**（越靠后文件越小也越糊）→ 可选改输出格式（**Same** 保持原格式，或换 WebP 更小）→ 点 **Compress**。
   **你应该看到什么**：每张图处理后显示「压缩前 → 压缩后」的体积与百分比；多张时按钮变 **Download all as zip**。

2. **Convert（转换）**：拖入图片 → 在 **Convert to** 选 PNG / JPG / WebP → 有损格式（JPG/WebP）出现 **Quality** 滑杆 → 转 JPG 时出现 **Background behind transparency**（透明底会被填成这个颜色，默认白）→ 点 **Convert**。

3. **Resize（缩放）**：拖入图片 → **Resize by** 选 **Pixels**（填宽/高）或 **Percentage**（百分比滑杆）→ **Lock aspect ratio** 默认开（填一边，另一边自动跟）→ **Allow upscaling** 默认关（放大补不出细节）→ 点 **Resize**。

4. **Crop（裁剪）**：一次只处理一张图 → 拖出选区，或输入精确像素 → 右侧 **Aspect ratio** 选 **Free / 1:1 / 16:9 / 4:3 / 3:2 / 9:16** → 点 **Crop**。
   **你应该看到什么**：裁剪按原图分辨率输出，不会拿缩小后的预览图去裁。

5. **Rotate（旋转 / 翻转）**：拖入图片 → 选 **Rotate** 的 0° / 90° / 180° / 270°（顺时针）→ 可开 **Flip horizontally**（左右镜像）/ **Flip vertically**（上下镜像）→ 点 **Apply**。

### D2 · 六个格式转换直达页

在中心页底部 "Format converters" 一栏，六个直达页已预选好输出格式，省去「选格式」这一步：`/png-to-jpg`、`/jpg-to-png`、`/png-to-webp`、`/webp-to-png`、`/jpg-to-webp`、`/webp-to-jpg`。点进去就是一个把目标格式锁定的转换器，其余操作与 D1 的 Convert 相同。

**证据**：`app/[locale]/tools/page.tsx`、`components/tools/ToolPage.tsx`、`ToolWorkspace.tsx`、`CropWorkspace.tsx`、`ToolOptions.tsx`、`lib/image-tools/ops.ts`、`lib/seo/tools.ts`。

## 迁移练习

**任务**：走通一条和跟做不同的支线，并说清它从主路径哪一步分出。

- 可用条件：任选「代码出图」「动画 + 视频导出」「图片工具集」中的一条；素材自备（一段代码 / 一张已做好的图 / 一组要压缩或转格式的图片）。
- 怎样算做成：产出一张代码图、一个视频文件，或一批处理后的图片；并能用一句话说明「这条支线从主路径的哪一步分出（或为何不经主路径）、做完回到哪一步」。
