# 04 · 支线能力

> 这一课写主路径之外的支线，并且**每条都说明它从主路径哪一步分出去**。
> 只写仓库里真实存在、且当前编辑器里能点到的支线：代码出图、推文出图、动画与视频导出、多图幻灯片。

---

## 本课目标

1. 说清三条支线各解决什么、从主路径哪里分出、做完后回到哪里。
2. 至少走通一条支线（推荐推文出图，最短）。
3. 知道公开截图 API 存在，但不属于编辑器主路径，不进本课正文。

---

## 它在模型的哪一格

支线都挂在主路径的某一步上分叉：

```
主路径：① 获得画面 → ② 定画幅 → ③ 样机/画框 → ④ 背景/深度 → ⑤ 标注/文字 → ⑦ 导出
                ↑                      ↑                                    
           支线：推文出图          支线：动画（⑥）→ 视频导出
        （用推文链接代替上传）     （在 ③④ 之后加动效，或加多图）
另：代码出图是独立页 /code，不经过主路径。
```

---

## 支线 A · 推文出图（最短，推荐先走）

**从哪分出**：① 获得画面。不传图，改用一条推文链接。

1. 打开编辑器，左侧 Design 面板里找到 **Add a Tweet**，展开。
2. 粘贴一条推文 URL（如 `https://x.com/user/status/123…`）或纯数字 ID。
3. 点 **Fetch tweet**，等它拉取并预览。
4. 用 Light / Dark 切换预览样式，满意后点 **Add to canvas**。

**你应该看到什么**：推文变成一张规整的卡片进入画布，之后可继续走 ②③④⑤ 的主路径。

**证据**：`components/editor/sections/TweetImportSection.tsx`、`app/api/tweet/[id]/route.ts`。

## 支线 B · 代码出图（独立页）

**从哪分出**：不经过编辑器主路径，直接访问 `/code`（线上 `screenshot-studio.com/code`）。

1. 打开 `/code`，看到一段默认代码示例。
2. 粘贴你的代码，底部控制条选 **Theme**（14 个主题）、**Language**（21 种）、**Background**（主题渐变 / 图片 / 图案，可关闭得透明底）、**Dark mode**、**Line numbers**、**Padding**（16/32/64/128）、**Window**（None / Mac）。
3. 点 **Export Image**（或按 `Cmd/Ctrl+S`）。

**你应该看到什么**：下载一张 `code-image.png`（可到 2x / 4x）。也可 **Copy Image**（`Cmd/Ctrl+Shift+C`）或 **Copy URL** 分享当前状态。

**证据**：`app/[locale]/code/page.tsx`、`components/code-image/CodeImageEditor.tsx`、`code-themes.ts`。

## 支线 C · 动画与视频导出

**从哪分出**：③④ 之后（画面已成型，想让它动起来），或加多图做幻灯片。

### C1 · 加动画

1. 右栏切到 **Motion** 标签，看到按 8 类分组的动画预设（Reveal / Slide / Fade / Flip / Perspective / Orbit / Depth / Ken Burns，共 35 个）。
2. 点一个预设卡片，画布下方自动出现时间轴。

**你应该看到什么**：动画被加进时间轴，卡片显示时长（如 1.2s），可点播放预览。

### C2 · 多图幻灯片

1. 顶部点 **Add Slide**，选多张图加入。

**你应该看到什么**：画布支持多页切换，Header 出现 **Export All（N）** 打包下载按钮。

### C3 · 导出视频

1. 点顶部 **Export Video**。
2. 弹窗里选 Export Type（Animation / Slideshow）、Format（MP4 H.264 / WebM VP8）、Quality（High / Medium / Low）；Slideshow 还可设每张时长。
3. 点 **Export as MP4/WebM**。

**你应该看到什么**：进度条走完，下载视频文件；MP4 需要支持 WebCodecs 的浏览器（Chrome 94+ / Edge 94+），不支持时按钮会提示。

**证据**：`components/editor/RightSettingsPanel.tsx`（Motion）、`lib/animation/presets.ts`、`components/timeline/`、`lib/export-slideshow-dialog.tsx`、`lib/export/video-encoder.ts`。

## 迁移练习

**任务**：走通一条和跟做不同的支线，并说清它从主路径哪一步分出。

- 可用条件：任选「代码出图」或「动画 + 视频导出」中的一条；素材自备（一段代码 / 一张已做好的图）。
- 怎样算做成：产出一张代码图或一个视频文件；并能用一句话说明「这条支线从主路径的哪一步分出、做完回到哪一步」。
