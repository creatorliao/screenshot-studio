## 一句话结论

**功能不是不够，而是没有为任何一条用户旅程编排过。**

15 条导入入口、318 个背景候选（全部无名 32px 色块）、14 处死代码 UI、3 套"有没有图"的判据、
桌面 5 个 / 移动 6 个互不一致的 Tab，全部平铺在同一个 260px 侧栏 + 一个 340px 弹窗里。

用户面对的不是"功能少"，而是**每一步都要先做一次考古**：

- **不知道怎么上传**：头部**没有**「导入」按钮；唯一入口绑在"空画布"状态上，有图即消失；
  而空画布时左右两个面板**照样全量渲染**，一堆控件可点但什么都不发生。
- **改背景按钮不方便**：318 个候选堆在约 212px 宽的纵向长条里，渐变色块 32px、**无名字**、
  **无 hover 预览**、无搜索、无收藏、滚动条被 CSS 隐藏、11 个分组每次进来全展开、
  从"光与影"滚到"渐变"约 3 屏，两个横向画廊分别有 4.7 屏和 10.7 屏的内容。

**病根：功能按"实现分类"堆叠，没有按"用户动作顺序"编排。**

## 推荐路线

**方案 B（中改）**：把工具从"功能面板集"改造成"五步流水线"——

```
① 导入图片 → ② 调整图片 → ③ 设置背景 → ④ 加文字与标注 → ⑤ 导出
```

左侧**步骤条**（替代现在的 3 个 Tab + 模式开关）、右侧**只显示当前步骤的属性面板**、
高级能力（3D 透视 / 动画时间轴 / 设备样机 / 推文代码导入）收进末尾的「⚙ 高级」抽屉。

不建议方案 A（治不了根本问题），不建议方案 C（成本/收益比不合理，
且与用户"不要为了好看而乱搞"的要求冲突）。
