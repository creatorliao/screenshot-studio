# 附录 · 卡住时看这里

> 按「症状」查表。每一条都来自仓库里真实存在的失败点，不编造。

---

## 安装 / 启动

| 症状 | 原因 | 处理 |
|------|------|------|
| `npm run dev` 报 Node 版本相关错误 | 需要 Node.js 20+ | `node -v` 确认版本，升级到 20+（`CONTRIBUTING.md` 要求） |
| `npm install` 很慢或失败 | 依赖多、网络问题 | 重试；或换镜像源后重试 |
| `npm run dev` 因 Prisma 报错 | `dev` 脚本先执行 `npx prisma generate`，Prisma 需要 `DATABASE_URL` | 核心功能不需要数据库；如需本地跑通，配置一个 PostgreSQL 的 `DATABASE_URL` 到 `.env.local`（见下方「环境变量」） |
| 打开 `localhost:3000` 不是编辑器 | 端口被占用或没启动成功 | 看终端输出；换端口或用线上版 `screenshot-studio.com` 先体验 |

## 环境变量

- **核心功能不需要任何环境变量**（`README.md`、`CONTRIBUTING.md` 均写明）。
- 只有要用 **Cloudflare R2**（素材存储）、**Postgres 截图缓存**、**分析** 时才需要配置。
- 本仓库**没有提交 `.env.example`**（`.gitignore` 忽略 `.env*`）。所以「复制 `.env.example`」这一步在本源码树里找不到文件，这是正常的。需要时按 `CONTRIBUTING.md` 的说明自行创建 `.env.local`，不要虚构内容。

## 上传

| 症状 | 原因 | 处理 |
|------|------|------|
| 拖入图没反应 / 报「File type not supported」 | 只支持 PNG / JPG / WEBP | 转成这三种格式之一再传（`lib/constants.ts` 的 `ALLOWED_IMAGE_TYPES`） |
| 报「File size too large」 | 单张上限 100MB | 压缩后再传（`lib/constants.ts` 的 `MAX_IMAGE_SIZE`） |
| 粘贴不生效 | 剪贴板里不是图片 | 复制的是图片才行；文字不会被当作图片 |

## 网页截图

| 症状 | 原因 | 处理 |
|------|------|------|
| 输入网址点 Capture 没反应 / 报错 | URL 不合法或站点拒绝抓取 | 补全 `https://`；有些站点（需登录、反爬）截不了，换一个公开页面 |
| 截图是桌面/移动尺寸不对 | 默认 Desktop 1920×1080 | 切换 Device Type 为 Mobile（375×667） |

## 浏览器限制（视频导出）

| 症状 | 原因 | 处理 |
|------|------|------|
| 导出视频时 MP4 按钮置灰 / 提示「Browser not supported」 | MP4 需要 WebCodecs 支持（Chrome 94+ / Edge 94+） | 换 Chrome/Edge，或改用 WebM |
| 首次导出视频很慢 | FFmpeg WASM 需要加载（2–5 秒） | 弹窗打开时会预加载，稍等即可 |
| 关闭导出弹窗就中止 | 关闭即取消导出 | 导出中别关弹窗 |

## 导出图片失败

| 症状 | 原因 | 处理 |
|------|------|------|
| 点了 Export 没下载 | 浏览器下载被拦截 / 弹窗被阻止 | 允许下载；检查浏览器下载栏 |
| 导出没图或空白 | 画布里没有内容 | 先放入一张图再导出 |
| 想透明背景却得到白底 | 格式或背景没选对 | 用 PNG 格式，并把背景设为 **Transparent**（BG 标签的 Custom Background） |

## 其它

| 症状 | 处理 |
|------|------|
| 改乱了想回到初始 | 顶部 **Reset**（重置画布设置）或 **Remove**（移除图片） |
| 误操作 | 顶部撤销 `Cmd/Ctrl+Z`、重做 `Cmd/Ctrl+Shift+Z` |
| 想下次接着做 | 编辑器会**自动保存草稿**（无需手动）；导出偏好也会被记住 |
