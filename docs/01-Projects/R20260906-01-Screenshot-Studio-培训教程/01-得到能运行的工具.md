# 01 · 得到能运行的工具

> 这一课解决「启动」。读完你要能打开线上版，或本地安装并进入编辑器，且知道哪些配置可以先不管。

---

## 本课目标

1. 打开线上版 `screenshot-studio.com`，或在本机 `npm run dev` 启动并看到同一个编辑器。
2. 说清核心功能不需要环境变量；R2 / 数据库 / 分析都是可选项。
3. 遇到首次启动报错时，能去「附录-卡住时看这里」找到对应条目，而不是被卡住。

这一课落在心智模型的**第 0 步：进入编辑器**，即 ① 获得画面之前。

---

## 它在模型的哪一格

模型是 `① 获得画面 → ② 定画幅 → … → ⑦ 导出`。本课不占任何一格，它是**走到 ① 之前的门槛**。只有进了编辑器，你才能开始 ①。

---

## 跟做步骤

### 路径 A · 线上版（只想先用起来）

1. 打开浏览器，访问 `https://www.screenshot-studio.com`。
2. 页面直接进入编辑器，中央是一个「＋」和一行字：*"Drag & drop, click to browse, or paste"*（拖入、点击浏览、或粘贴）。

**你应该看到什么**：一个没有注册、没有登录、没有水印提示的编辑器，顶部有一排按钮（Templates、撤销/重做、画幅、Copy、Save），左右两侧有面板。这就是「能用了」。

### 路径 B · 本地启动（要对照源码学）

1. 确认环境：Node.js 20+ 与 npm（`CONTRIBUTING.md` 要求）。命令行检查：

   ```bash
   node -v
   npm -v
   ```

2. 进入仓库并安装依赖：

   ```bash
   git clone https://github.com/opennookorg/screenshot-studio.git
   cd screenshot-studio
   npm install
   ```

3. 启动开发服务器：

   ```bash
   npm run dev
   ```

4. 浏览器打开 `http://localhost:3000`。

**你应该看到什么**：终端打印 Next.js 开发服务器的启动信息，浏览器出现和线上版一致的编辑器。

### 哪些配置可以先不管

- **不需要**任何环境变量就能做核心的事：上传、截网页、套样机、调背景、标注、导出图片。
- **可选**：Cloudflare R2（外部素材存储）、Postgres（截图缓存）、分析（analytics）。只有需要这些能力时才配。

**证据**：`README.md`（*"Core features need no environment variables"*）、`CONTRIBUTING.md`（*"Core features work with no configuration"*）。

> 注意：本仓库**没有提交** `.env.example`（被 `.gitignore` 忽略）。如果你在文档里看到「复制 `.env.example`」，它不在源码树里。要不要配，取决于你是否用 R2/数据库/分析——不配不影响编辑器主路径。

## 迁移练习

**任务**：换一种方式再进一次编辑器。

- 如果你刚才用线上版，现在用本地版（或反过来）。
- 可用条件：本地版需要 Node 20+ 与 npm；网络下载依赖可能需要一点时间。
- 怎样算做成：你在两种方式里都看到同一个空态上传区，并能说出线上与本地编辑器的界面是一样的。
