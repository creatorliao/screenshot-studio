## 一、作者意图：这套工具是干什么的

Screenshot Studio 是一个**在浏览器里运行、无需注册、无水印**的开源「截图编辑器 + 样机制作器」。它的目标不是替代 Photoshop，而是让你把一张普通截图，**一次**做成可以发出去的东西：

- 产品截图、界面样机（给设计师）
- 代码图、README 配图、App Store 截图（给开发者）
- 落地页图、社媒图、广告、推文图（给营销）

作者自己的三步说法是：**Drop Your Image → Style It → Export**（丢一张图 → 美化 → 导出）。

> 关键心态：先想「这张图给谁看、用在哪」，再选画幅与样机，再调背景与标注，最后才选导出格式。工具的顺序就是按这个决策顺序设计的。

**证据**：`README.md`、`app/[locale]/landing/page.tsx`、`app/[locale]/for/designers/page.tsx`、`for/developers/page.tsx`、`for/marketers/page.tsx`。

## 二、心智模型（7 格，本系列唯一的一套节点名）

后面每一课都用下面这 7 个名字定位自己，不会另起别名：

```
① 获得画面 → ② 定画幅 → ③ 套样机与画框 → ④ 调背景与深度 → ⑤ 标注与文字 → ⑥ 加动效(支线) → ⑦ 导出
```

| 格 | 你在做什么 | 界面上在哪 |
|----|-----------|------------|
| ① 获得画面 | 上传 / 粘贴一张图，或输入网址截网页，或导入推文 | 打开编辑器时的空态上传区 |
| ② 定画幅 | 选这张图的比例（如 16:9、1:1、Story） | 顶部 Header 的画幅选择器 |
| ③ 套样机与画框 | 把图片装进浏览器窗、手机/笔记本样机，或加玻璃/描边样式 | 左栏 Image / Browser / Device 三种模式 |
| ④ 调背景与深度 | 换背景、加阴影、叠贴纸与 3D 物体、管图层 | 左栏 BG 标签、Layers 标签 |
| ⑤ 标注与文字 | 画箭头/方框/模糊区，加文字 | 左栏 Design 面板的 Draw & Markup、Add Text |
| ⑥ 加动效（支线） | 选动画预设、拖时间轴、做多图幻灯片 | 右栏 Motion、画布下方 Animate、时间轴 |
| ⑦ 导出 | 选格式/质量/倍率，下载图片或视频 | 顶部 Header 的 Save / Copy / Export Video |

**记忆锚点**：前三格回答「画面从哪来、长成什么样」，中间三格回答「怎么让它好看」，最后一格回答「怎么交出去」。

## 三、主路径与支线

- **主路径（人人要会）**：① 获得画面 → ② 定画幅 → ③ 样机/画框 → ④ 背景/深度 → ⑤ 标注/文字 → ⑦ 导出 PNG/JPEG/WebP。
- **支线（按需学）**：
  - **代码出图**：独立页 `/code`，粘贴代码 → 选主题/背景 → 导出 PNG。
  - **推文出图**：在 ① 用推文链接代替上传图片。
  - **动画 / 视频导出**：在 ③④ 之后加动效，或加多张图做幻灯片，最后导出 MP4/WebM。
- **不是本系列主路径**：产品另有一个公开截图 API（`/docs`），代码里真实存在，但用编辑器做图不需要它。附录带一句即可。
