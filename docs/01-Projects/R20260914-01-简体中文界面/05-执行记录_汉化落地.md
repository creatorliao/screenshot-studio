## 三、执行中发现的 6 个"静默损坏"陷阱（重要）

这次改造最大的风险不是翻译量，而是**改坏了却仍能构建**。逐个记录，便于复盘：

### 陷阱 1：引号重复

`encodeLiteral` 补了引号，而替换区间只覆盖引号**内部**，产出 `aria-label=""模板""`。
→ 修：转义函数不再补引号（`scripts/lib/i18n-detect.ts`）。
→ 发现方式：人工抽查 diff。

### 陷阱 2：逻辑值被翻译（已导致构建失败）

`app/[locale]/changelog/page.tsx` 的

```ts
{(["added", "improved", "fixed"] as const).map((type) => {
  const items = entry.changes.filter((c) => c.type === type);
```

枚举值被译成 `["已添加", "已改进", "已修复"]`，`c.type === type` 类型不匹配。
→ 修：`isRenderPosition` 排除数组字面量中的短枚举 token。
→ 发现方式：**构建报错**（这是唯一被构建拦下的一类）。

### 陷阱 3：`jsxExpr` 与 `dataProp` 双通道重复记账

同一区间被两条通道各记一次，从后往前替换时二次替换，直接改坏源码（26 处）。
→ 修：按区间去重。
→ 发现方式：写审计脚本主动扫描。

### 陷阱 4：`jsxExpr` 里的逻辑值

351 处 `jsxExpr` 中 **170 处是逻辑值**（`e.key === 'Enter'`、`setMode('gradient')`、`'tl'`、`'mac'`）。
→ 修：引入 `isRenderPosition`，只保留渲染位。
→ 发现方式：子智能体回报 + 审计脚本。

### 陷阱 5：`looksLikeClass` 关键词表误伤（两类）

- 旧版把 `grid` 作为整词依据 → `"Toggle grid"`、`"Border radius"` 被当成 CSS 类名丢弃。
- 收紧后又引入新问题：Tailwind 前缀表含 `pointer-` → 含 `"pointer-events"` 的长句被整句丢弃
  （changelog 真实条目 `Image overlay resize and rotate handles now work reliably. Fixed pointer-events ...`）。
→ 修：先判"明确是文案"的特征（词首大写、句子标点、长度 > 60），再看是否像类名。
→ 发现方式：**运行期验证**（页面残留英文）反查源码。

### 陷阱 6：三类结构性漏网

| 漏网类型 | 实例 | 处理 |
|---|---|---|
| 模块顶层**展示文案数组** | `const FEATURES = ["100+ gradient, mesh, ..."]` | 新增"展示形态"判定（长句多词才收，短枚举不收） |
| **模板字符串** | `` `${from} to ${toLabel} Converter: Free, No Upload` `` | 字典替换无法覆盖，改为手工改写源码 |
| **用户可见提示**（函数实参） | `toast.success('Video exported successfully!')` | 新增独立收集通道，白名单 `toast/alert/confirm/setError`（`console.*` 刻意不收） |

### 教训

> **只有构建能拦下"类型层面的损坏"；语义层面的损坏（`'Enter'`→`'回车'`、`'tl'`→`'左上'`）构建完全看不出来，
> 必须靠"审计脚本 + 运行期可见文本比对"两道闸门。**

因此本次交付的是一套**带闸门的工具链**，而不是一次性脚本。

## 四、交付的工具链

| 脚本 | 作用 |
|------|------|
| `scripts/i18n-inventory.ts` | AST 精确清点用户可见文案（分 JSX 文本/属性/表达式/数据属性四通道） |

| `scripts/i18n-delta.ts` | 漏网增量清点（对英文原文跑，避免把中文当新文案） |
| `scripts/i18n-apply.ts` | codemod：`--write` 写盘 / `--restore` 从备份还原 / 默认 dry-run |
| `scripts/i18n-verify.ts` | 运行期验证：抓页面、剔 script/style、统计可见中文与残留英文 |
| `scripts/i18n-template-scan.ts` | 模板字符串文案扫描（字典覆盖不到的那一类） |

| `i18n-work/zh-extra*.json` | 增量字典（英文原文 → 中文），共 394 条 |
| `i18n-work/backup/` | 每次写盘前的文件备份（可用 `--restore` 整体回退） |

